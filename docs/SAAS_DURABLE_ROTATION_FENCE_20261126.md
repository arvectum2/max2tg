# P0.5b / P2.2b — durable single-grant rotation fence

Base a3b5f91 (PR #67). RotationFence holds an exclusive owner-private lock and retains the exact reviewed old/new bundles, nonce, namespace device/inode, keeper PID/start time, Linux boot identity and kernel object handles. ARMED is published without overwrite; IN_FLIGHT is atomically persisted and fsynced before the single kernel mutation; KERNEL_VERIFIED is persisted before the success receipt may be returned. Reopening is read-only evidence classification, not authority to re-arm, replay, adopt or launch. Identity and exact ruleset/handle checks remain required. An independently retained, trusted anchor directory is a caller precondition; this is a single-grant fence, not a multi-generation production controller or rollback-resistant storage against an authorized filesystem writer. Missing, corrupt, foreign or ambiguous evidence cannot authorize launch. No automatic retry or rollback after uncertainty.

Actual isolated Linux kernel tests kill a controller process with SIGKILL at three boundaries: before nft mutation (IN_FLIGHT, old policy matches); after nft mutation (IN_FLIGHT, replacement matches); after verified state persisted but before receipt delivered (KERNEL_VERIFIED, replacement matches). A fresh controller opens the same anchor, verifies exact kernel state and refuses both re-arm and replay. No policy mutation during observation. These crash trials have no live broker, and are distinct from the successful actual gateway/worker journal fixture, now using the persistent fence and verifying it again after reopening. That fixture passed with exact three MAX/two Telegram effects, ACKED/UNKNOWN/ACKED central and SENT/UNKNOWN/SENT worker outcomes, no duplicates, and 73 allowed/7 blocked packets. 91 targeted unit tests and Ruff passed. Initial local pytest lacked cryptography; reran with the existing locked dependency 50.0.2, no dependency change. Actual Docker tests use disposable namespaces and tmpfs; abrupt process loss tested, host power loss and durable storage rollback not tested. CI adds all three SIGKILL boundaries; remote CI pending.
