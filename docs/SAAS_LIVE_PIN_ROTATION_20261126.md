# P0.5b / P2.2b — live broker pin generation transition

Base cd9d82b (PR #62). The broker pauses admission, increments an in-process generation fence, aborts revoked upstream sockets before the kernel update, preserves registered streams whose exact role/IP remains approved, and permits new dials only after an exact success receipt from a trusted controller. Pending dials from the previous generation cannot be admitted even if their IP remains permitted. The controller's verified transaction checks complete old/new rulesets and unchanged object handles, without automatic retry. Failure, cancellation, invalid receipt, stop or elapsed deadline fail closed; retained streams are aborted and listeners are torn down. Expiry monitoring remains active during update; conservative monotonic deadlines are not extended by a slow callback. No retry of message operations. The async callback must be trusted and have exclusive namespace ownership; receipt is not independent attestation. The controller may complete an ambiguous external mutation after cancellation, so the namespace must be investigated before reuse. No external launch authority, persistent fence or production IPC/privilege orchestration.
