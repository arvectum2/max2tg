# MAX2TG — P0.3, синхронизация изменений (23.10.2026)

## Поддерживаемые сценарии

- MAX opcode 128 со статусом EDITED → редактирование соответствующего
  bot-authored Telegram-текста или подписи (editMessageText/editMessageCaption).
- MAX opcode 142, точное одиночное удаление → Telegram deleteMessage
  только для ранее отправленных самим мостом сообщений и частей из outbox.
- MAX opcode 155/156 reactionInfo.yourReaction → реакция бота в Telegram.
  Агрегированные чужие реакции не приписываются пользователю.
- Telegram edited_message → MAX opcode 67, со всеми обязательными
  полями (elements, attachments), только при существующем ID mapping.
  Новое сообщение не создаётся.
- Telegram message_reaction разрешённого участника → MAX opcode 178/179.
- SQLite message_mutations обеспечивает дедупликацию, устойчивость
  к рестарту, сравнение updateTime и безопасное отложенное применение.
- При догрузке истории известные отредактированные сообщения обновляются
  в Telegram по прежнему ID.

## Границы безопасности

- Опкод MAX 66 (удаление у всех) не вызывается: сообщество описывает
  watermark/cascade bug, способный удалить нецелевые сообщения.
- Bot API не сообщает обычные удаления пользовательских Telegram-сообщений,
  поэтому удаление в Telegram не воспроизводится в MAX.
- Массовые события удаления MAX (opcode 140 и списки с несколькими ID)
  игнорируются для предотвращения случайного удаления многих сообщений.
- Нет подтверждённых bot-owned outbox parts → не редактируем/не удаляем
  пользовательское Telegram-сообщение, даже при наличии старого mapping.
- Длинные отредактированные тексты и подписи сверх лимита безопасной
  единичной замены пока получают BLOCKED: многосоставные правки требуют
  отдельной операции синхронизации всего набора частей.
- Telegram ограничивает удаление по возрасту, правам и принадлежности.
- Если Telegram deleteMessage дал неопределённый timeout, событие получает
  UNKNOWN и не повторяется автоматически.
- Схемы MAX reverse-engineered, поэтому неподтверждённые или неоднозначные
  события не вызывают внешних действий.
- Сквозные destructive-тесты с реальными собеседниками не выполняются.
