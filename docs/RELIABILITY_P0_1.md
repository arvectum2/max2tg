# MAX2TG Reliability v1.1 — P0.1: восстановление истории

Реализовано 23.10.2026. При авторизации / переподключении MAX бот
проходит по уже привязанным активным чатам с существующими Telegram-темами.

## Алгоритм

1. Загружаем persisted history cursor из TopicStore (ключ sync). Если
   курсора нет, используем уже отображённый MAX message ID как безопасный
   anchor и ищем более свежие сообщения.
2. История запрашивается с newest назад страницами по 100 сообщений
   через opcode 49. По умолчанию максимум 10 страниц/чат за проход.
3. Для каждого сообщения сверяем наличие MAX → TG mapping; импортируем
   недостающие сообщения по времени от старых к новым с обычной
   обработкой текста, reply, forward, медиа и исходящих сообщений владельца.
4. За синхронизацию отвечает общий per-chat asyncio.Lock: live события
   того же чата не отправляются параллельно с историей.
5. После успешного импорта ВСЕХ недостающих элементов окно
   закрывается сохранением максимального timestamp в sync.
6. При ошибке RPC, лимите окна или частичной доставке курсор не
   продвигается — следующая синхронизация повторит проверку.
7. Если исходный чат существует, но нет ни cursor, ни известного
   mapping-anchor, сохраняем безопасный baseline времени БЕЗ массового
   импорта старой переписки.

## Ограничения первого среза

- История свыше 1000 сообщений между anchor и текущим моментом оставляется
  без автоматического импорта (no cursor advance, warning в логах). Нужна
  настройка пакетной прогрессии и мониторинг backlog в P0.2/P0.4.
- Если до включения P0.1 уже были неизвестные/несопоставленные сообщения,
  восстановить их без риска дублей невозможно: baseline не докачивает
  старую историю. Для этого остаётся ручной импорт через меню.
- Хранение cursor и message mapping остаётся в JSON и не заменяет
  будущую durable outbox. Таймаут Telegram после фактической отправки
  может давать неоднозначный результат.
- Результат зависит от корректной выдачи истории MAX opcode 49.
  При изменениях неофициального API нужны повторные интеграционные тесты.
