# P2.2b — onboarding-driven lifecycle reconciliation

Base: main 3e336b4 (merged PR #14). Offline development only; P2.2b remains open.

Managed gateway mode is explicit and external-only. It opens dedicated pre-mounted IPC listeners only for ACTIVE onboarding rows with active external capsules, active forum route and the verified bot identity. Registered but unactivated sessions have no listening egress socket. Reconcile opens newly activated listeners and closes revoked ones under the delivery lock. No new host mounts, arbitrary paths or tenant commands. Routes are disabled in the registry before teardown. A request already in flight cannot be recalled; UNKNOWN handling is unchanged.

LifecycleReconciler consumes a trusted gateway snapshot on the host, not user input. The full registered session set, booleans and snapshot age (10 seconds, 2 seconds forward skew) are validated before mutation. The timestamp checkpoint persists with desired state in one SQLite transaction to reject older snapshots after supervisor handoff. An active but unready channel gates new starts without resetting the crash budget. Inactive sessions stop their own container, not other tenants; data volumes are retained. Stale, malformed or unavailable snapshots do not authorize start/stop; running workers are not force-killed. The synthetic host reads via trusted docker exec. This is not a signed distributed lease, production remote protocol or guarantee of immediate revocation while the controller is unavailable.

Actual Docker smoke: second user provisioned but inactive, no worker created or start attempt spent; activation opens channel and launches worker. Existing two-user delivery, idle crash recovery, supervisor handoff and post-send UNKNOWN quarantine pass. Revocation of A closes its listener and stops A; B handles another update while A's new update is not admitted. Final gateway evidence: five ingress ACKED, one UNKNOWN, two egress SENT; A has three launches, B one. No replay of the uncertain send; all disposable resources removed. The gateway and worker use fake messenger API boundaries. The local provisioning evidence for delayed activation is trusted synthetic setup evidence, not a remote attestation.

Initial unit fixture used an overlong macOS Unix socket path; corrected to a short private temporary directory and reran. Existing 33 PTB deprecation warnings. No personal service, real account or real secret modified.
